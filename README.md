# Proyecto de aprendizaje sobre ETF e inversión en Colombia

## Propósito

Este repositorio es un sistema estructurado de aprendizaje personal para comprender:

- Fondos cotizados en bolsa (ETF)
- Productos de inversión colombianos
- Cuestiones fiscales y de declaración transfronteriza
- Seguridad de corredores, plataformas y cuentas
- Construcción de portafolios
- Flujo de caja durante la jubilación
- Propiedades en dificultades financieras y procesos de ejecución
- Operación de propiedades en alquiler
- Controles de renovación
- Compra y venta de propiedades
- Prevención del fraude
- Documentación de inversiones

Este repositorio tiene fines educativos.

No proporciona asesoría individualizada de carácter legal, tributario, financiero, crediticio, de inversión ni inmobiliario.

## Principios fundamentales

1. Preservar la liquidez del hogar.
2. Proteger las reservas de emergencia.
3. Comprender cada producto antes de invertir.
4. Verificar las instituciones de manera independiente.
5. Utilizar fuentes primarias y oficiales.
6. Documentar los supuestos y las decisiones.
7. Incluir comisiones, impuestos y efectos cambiarios.
8. Someter las decisiones importantes a pruebas de estrés.
9. Obtener la revisión de profesionales cualificados cuando sea necesario.
10. Considerar la decisión de no actuar como una opción válida.

## Revisión profesional necesaria

Debe considerarse la asesoría profesional antes de:

- Comprar una inversión colectiva constituida fuera de Estados Unidos
- Realizar una determinación sobre una PFIC
- Presentar formularios tributarios transfronterizos
- Seleccionar estructuras de planificación patrimonial
- Comprar una propiedad en una subasta judicial o de la DIAN
- Firmar una promesa de compraventa de propiedad
- Pagar un depósito inmobiliario significativo
- Aceptar financiación hipotecaria o denominada en UVR
- Retirar a un ocupante de una propiedad
- Firmar un contrato de arrendamiento
- Iniciar una renovación estructural
- Vender una propiedad con gravámenes pendientes
- Realizar una transferencia transfronteriza de gran cuantía

## Seguridad del repositorio

No incluya en el repositorio:

- Contraseñas
- Códigos de autenticación multifactor
- Frases de recuperación
- Claves privadas
- Números completos de cuentas
- Números completos de identificación
- Historias clínicas
- Declaraciones de impuestos
- Extractos bancarios
- Contratos privados que contengan datos personales
- Documentos de identidad de arrendatarios
- Documentos legales sin anonimizar

Almacene los registros confidenciales en una ubicación cifrada y con control de acceso.

## Regla final de preparación

Ninguna inversión se aprueba únicamente porque el repositorio contenga una lista de verificación.

Cada operación debe evaluarse utilizando información vigente sobre:

- Documentos oficiales
- Datos de mercado
- Comisiones
- Normas tributarias
- Situación jurídica
- Registros de propiedad
- Circunstancias financieras personales

Cuando falte evidencia material, el estado correcto es:

**Solo investigación; no realizar ninguna operación.**
