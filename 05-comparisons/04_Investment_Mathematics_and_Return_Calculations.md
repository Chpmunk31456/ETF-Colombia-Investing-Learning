# Lesson 29 — Investment Mathematics, Return Calculations, and Comparison Standards

## Learning Objective

Learn how to calculate and compare nominal return, real return, annualized return, total return, yield, investment income, property return, currency effects, fees, and portfolio performance.

## Important Principle

Investment results can appear better or worse depending on the measurement used.

A valid comparison should use:

- The same time period
- The same currency
- Similar treatment of taxes
- Similar treatment of fees
- Comparable risk
- Comparable liquidity
- Accurate cash-flow dates
- Consistent assumptions

Do not compare unlike numbers.

## Required Calculation Inputs

Before calculating return, record:

- Initial investment
- Investment date
- Additional contributions
- Contribution dates
- Withdrawals
- Withdrawal dates
- Income received
- Income dates
- Fees
- Taxes
- Ending value
- Valuation date
- Currency
- Exchange rates

Missing cash-flow dates can materially distort the result.

## Gain or Loss

Basic gain or loss equals:

Ending value
minus initial investment

Example:

- Initial investment: COP 10,000,000
- Ending value: COP 10,800,000

Gain:

COP 800,000

This calculation is incomplete when there were:

- Contributions
- Withdrawals
- Income payments
- Fees
- Taxes

## Simple Return

Simple return percentage equals:

Gain or loss
divided by initial investment

Example:

- Gain: COP 800,000
- Initial investment: COP 10,000,000

Simple return:

8%

Simple return does not account for how long the investment was held.

## Total Return

Total return includes:

- Price appreciation or decline
- Interest
- Dividends
- Distributions
- Realized gains
- Fees where included

General formula:

Total return =
Ending value
plus income received
minus initial value
minus additional net contributions

The calculation must treat contributions and withdrawals correctly.

## Price Return Versus Total Return

### Price return

Measures only the change in market price.

### Total return

Includes income such as:

- Dividends
- Interest
- Fund distributions

An income-producing investment should generally be evaluated using total return, not price return alone.

## Gross Return Versus Net Return

### Gross return

Return before:

- Fees
- Taxes
- Currency conversion
- Transaction costs

### Net return

Return after applicable costs.

Net return is more relevant to the investor.

## Nominal Return

Nominal return is the stated or observed percentage return without adjusting for inflation.

Example:

- Investment return: 9%
- Inflation not considered

Nominal return:

9%

## Real Return

Real return adjusts for inflation.

Approximate formula:

Real return ≈ nominal return minus inflation

More precise formula:

Real return =
(1 + nominal return)
divided by
(1 + inflation rate)
minus 1

Example:

- Nominal return: 10%
- Inflation: 7%

Approximate real return:

3%

More precise real return:

Approximately 2.8%

## Why Real Return Matters

An investment may increase in peso value while losing purchasing power.

Example:

- Investment grows by 6%
- Inflation is 9%

The nominal balance rises, but real purchasing power falls.

## Annualized Return

Annualized return converts a multi-period result into an equivalent yearly rate.

General formula:

Annualized return =
(Ending value divided by beginning value)
raised to the power of
(1 divided by years held)
minus 1

Example:

- Beginning value: COP 100,000,000
- Ending value: COP 121,000,000
- Holding period: 2 years

Annualized return:

10% per year

The total two-year return is 21%, not 20%, because of compounding.

## Holding-Period Return

Holding-period return measures return over the actual investment period.

It may cover:

- One month
- Six months
- Eighteen months
- Five years

Do not describe a holding-period return as annual unless it has been properly annualized.

## Compound Growth

Compound growth means returns are earned on:

- Original principal
- Previously accumulated returns

Future value formula:

Future value =
Present value
multiplied by
(1 + return rate)
raised to the number of periods

## Compounding Frequency

Possible compounding periods include:

- Daily
- Monthly
- Quarterly
- Semiannual
- Annual

Rates should be compared on a consistent effective annual basis.

## Effective Annual Rate

The effective annual rate includes the effect of compounding.

It differs from a nominal annual rate when compounding occurs more than once per year.

Before comparing CDTs or loans, confirm whether the quoted rate is:

- Nominal
- Effective annual
- Monthly
- Periodic
- Before fees
- After fees
- Before tax
- After tax

## Present Value

Present value estimates what a future amount is worth today using a discount rate.

General formula:

Present value =
Future amount
divided by
(1 + discount rate)
raised to the number of periods

Present value can help compare:

- Future property-sale proceeds
- Future CDT maturity values
- Deferred payments
- Pension payments
- Long-term investment outcomes

## Future Value

Future value estimates what a current amount may grow to.

Inputs include:

- Starting amount
- Return assumption
- Time
- Contributions
- Compounding frequency

Future value is a projection, not a guarantee.

## Rule of 72

The Rule of 72 provides a rough estimate of doubling time.

Approximate doubling years equals:

72
divided by annual percentage return

Example:

- Return: 8%

Estimated doubling time:

9 years

This is an approximation and ignores taxes, fees, and variable returns.

## Investment Income Yield

Income yield equals:

Annual income
divided by investment value

Examples of income include:

- Interest
- Dividends
- Net rental income

Yield does not measure total return.

## Dividend Yield

Dividend yield equals:

Annual dividends per share
divided by share price

A high dividend yield may reflect:

- Strong distributions
- Falling share price
- Elevated business risk
- Unsustainable payout

Dividend yield should not be evaluated alone.

## Distribution Yield

An ETF distribution may include:

- Dividends
- Interest
- Option income
- Capital gains
- Return of capital

A distribution yield is not necessarily the same as economic return.

## Yield on Cost

Yield on cost compares current annual income with the investor’s original cost.

It can describe income growth but is not an appropriate substitute for evaluating:

- Current market value
- Opportunity cost
- Total return
- Current risk

## Current Yield for Bonds

Current yield generally equals:

Annual coupon
divided by current bond price

It does not include:

- Gain or loss at maturity
- Reinvestment
- Default risk
- Fees
- Taxes

## Yield to Maturity

Yield to maturity estimates the return of a bond when:

- Held to maturity
- Payments occur as scheduled
- Coupons are reinvested as assumed
- No default occurs

It is an estimate rather than a guarantee.

## CDT Return

For a CDT, record:

- Principal
- Effective annual rate
- Term
- Gross interest
- Withholding
- Fees
- Net maturity value
- Inflation

Net real CDT return should be considered, not only the advertised rate.

## ETF Return

ETF return should include:

- Change in market value
- Dividends or distributions
- Expense ratio
- Trading costs
- Bid-ask spread
- Currency conversion
- Foreign withholding
- Tax consequences

## Property Gross Yield

Gross rental yield equals:

Annual gross rent
divided by total property cost

Total property cost should include:

- Purchase price
- Closing costs
- Initial legal costs
- Initial repairs
- Required improvements

Gross yield ignores ongoing expenses.

## Property Net Yield

Net rental yield equals:

Annual net operating income
divided by total property cost

Net operating income includes rent after operating expenses but before financing and income tax.

## Capitalization Rate

Cap rate equals:

Annual net operating income
divided by current property value

Cap rate is different from return on the investor’s original cost.

## Cash-on-Cash Return

Cash-on-cash return equals:

Annual pre-tax cash flow
divided by actual cash invested

It is useful for financed property.

It can be increased by leverage, but leverage also increases risk.

## Property Appreciation

Property appreciation equals:

Current property value
minus original property value

Appreciation should not be treated as realized profit until sale.

Expected sale costs and taxes should be considered.

## Property Economic Return

Economic property return should include:

- Net rental income
- Appreciation
- Renovation costs
- Financing costs
- Legal costs
- Vacancy
- Taxes
- Selling costs
- Currency effects

## Internal Rate of Return

Internal rate of return, or IRR, considers the timing of multiple cash flows.

It may be useful when an investment includes:

- Initial purchase
- Renovation payments
- Rental income
- Additional repairs
- Loan payments
- Sale proceeds

IRR can be misleading when:

- Cash-flow dates are wrong
- Future values are optimistic
- Multiple mathematical solutions exist
- Reinvestment assumptions are unrealistic
- It is compared with investments of different risk

## Money-Weighted Return

Money-weighted return reflects:

- Timing of deposits
- Timing of withdrawals
- Investment performance

It represents the investor’s personal experience more closely than a pure time-weighted measure.

## Time-Weighted Return

Time-weighted return attempts to remove the effect of investor cash flows.

It is useful for comparing:

- Fund managers
- Portfolios
- Investment strategies
- Benchmarks

## Dollar-Weighted or Peso-Weighted Return

Dollar-weighted and peso-weighted return are forms of money-weighted return using the chosen reporting currency.

The result depends on cash-flow timing.

## Currency Return

For a foreign investment, total return may have two components:

1. Investment return in the original currency
2. Currency movement against the investor’s reporting currency

Example:

- ETF gains 8% in USD
- USD weakens 5% against COP

The COP return will differ from 8%.

## Currency Gain or Loss

Currency gain or loss can arise from:

- Buying USD
- Converting investment income
- Selling foreign assets
- Paying fees
- Receiving pension income
- Repatriating property-sale proceeds

Track investment performance separately from currency performance.

## Approximate Combined Return

An approximate combined return may be calculated using:

Combined return =
(1 + asset return)
multiplied by
(1 + currency return)
minus 1

Simple addition is only an approximation.

## Fee Drag

Fee drag is the reduction in return caused by recurring or transaction costs.

Possible fees include:

- Expense ratio
- Broker commission
- Bid-ask spread
- Currency spread
- Custody fee
- Management fee
- Legal fee
- Property management
- Tax preparation

## Long-Term Effect of Fees

A recurring annual fee affects:

- Current-year return
- Future compounding
- Final portfolio value

A small percentage difference can become material over a long period.

## Tax Drag

Tax drag is the reduction in investment growth caused by taxes on:

- Interest
- Dividends
- Distributions
- Capital gains
- Property income
- Property sale
- Currency transactions

Tax drag varies by:

- Investor
- Account
- Jurisdiction
- Product
- Holding period

## After-Tax Return

After-tax return equals:

Net investment result after applicable taxes
divided by invested capital

Do not assume foreign withholding represents the final total tax obligation.

## Risk-Adjusted Return

A higher return is not automatically better when it requires substantially more risk.

Risk factors may include:

- Volatility
- Drawdown
- Leverage
- Credit risk
- Liquidity
- Currency risk
- Legal complexity
- Property concentration
- Occupancy risk

## Volatility

Volatility describes the variability of returns.

Higher volatility generally means a wider range of possible short-term outcomes.

Volatility does not measure every type of risk.

## Maximum Drawdown

Maximum drawdown measures the largest decline from a previous peak to a later low.

It helps answer:

- How large was the decline?
- How long did recovery take?
- Could the investor remain invested?

## Recovery Mathematics

Losses require larger percentage gains to recover.

| Loss | Gain Required to Recover |
|---:|---:|
| 10% | 11.1% |
| 20% | 25% |
| 30% | 42.9% |
| 40% | 66.7% |
| 50% | 100% |
| 60% | 150% |

This asymmetry is an important risk-control principle.

## Sharpe Ratio

The Sharpe ratio compares excess return with volatility.

General concept:

Return above a risk-free reference
divided by return volatility

Limitations include:

- Dependence on historical data
- Sensitivity to time period
- Assumption that volatility adequately represents risk
- Limited usefulness for illiquid property

## Benchmark Selection

A benchmark should match the investment.

Examples:

- Broad equity ETF versus its underlying equity index
- Bond ETF versus a similar-duration bond index
- CDT versus similar-term regulated deposits
- Rental property versus realistic local net rental returns
- Multi-asset portfolio versus a blended benchmark

Do not compare:

- A one-year CDT directly with a speculative equity fund
- Gross property appreciation with ETF total return
- COP return with USD return without adjustment
- Pre-tax return with after-tax return

## Benchmark Return

Benchmark return should use:

- Same time period
- Same currency
- Similar treatment of distributions
- Similar tax convention where practical
- Comparable investment category

## Opportunity Cost

Opportunity cost is the return or benefit forgone by choosing one investment over another.

Examples:

- Paying cash for property instead of holding ETFs
- Making extra mortgage payments instead of maintaining liquidity
- Holding a low-yield account instead of a CDT
- Buying a concentrated property instead of diversified assets

## Break-Even Analysis

Break-even identifies the point at which income or sale proceeds equal total costs.

For property, break-even may include:

- Purchase
- Repairs
- Financing
- Carrying costs
- Selling costs
- Taxes

For an ETF, break-even may include:

- Purchase price
- Commission
- Spread
- Currency conversion
- Selling costs

## Margin of Safety

Margin of safety protects against errors in:

- Valuation
- Repair estimates
- Rent
- Vacancy
- Fees
- Taxes
- Currency
- Sale price
- Timing

A projected return that disappears after a small assumption change has little margin of safety.

## Scenario Analysis

Calculate at least:

- Optimistic case
- Base case
- Conservative case
- Severe but plausible case

For each scenario, change:

- Return
- Income
- Fees
- Inflation
- Currency
- Holding period
- Sale price
- Repair costs
- Vacancy

## Sensitivity Analysis

Sensitivity analysis changes one input at a time.

Examples:

- ETF return decreases by 2 percentage points
- CDT renewal rate falls by 3 percentage points
- Property rent falls by 10%
- Repair cost rises by 20%
- COP strengthens by 15%

This reveals which assumptions matter most.

## Calculation Controls

Before accepting a calculation:

- Verify all inputs
- Confirm signs for inflows and outflows
- Confirm dates
- Confirm currency
- Confirm annual versus monthly rates
- Confirm effective versus nominal rates
- Include fees
- Include taxes where appropriate
- Check formulas
- Compare with an independent calculation
- Document assumptions

## Spreadsheet Controls

When using spreadsheets:

- Label input cells
- Separate inputs from formulas
- Protect formula cells where practical
- Avoid hidden assumptions
- Record source dates
- Use consistent currencies
- Review decimal and percentage formatting
- Test zero and negative cases
- Retain a clean original
- Document changes

## AI Calculation Controls

AI can help explain or structure calculations.

Do not rely on AI without independently checking:

- Arithmetic
- Formula
- Rate conversion
- Dates
- Currency
- Tax treatment
- Legal assumptions

## Common Calculation Errors

Common errors include:

- Treating total return as annual return
- Ignoring contributions
- Ignoring withdrawals
- Ignoring fees
- Ignoring inflation
- Ignoring tax
- Mixing COP and USD
- Adding compounded returns incorrectly
- Using gross rent as property return
- Treating unrealized gain as available cash
- Using asking price instead of sale price
- Comparing unequal time periods
- Comparing unequal risks

## Beginner Rules

1. Use the same time period when comparing investments.
2. Use the same reporting currency.
3. Include income, fees, and taxes.
4. Distinguish nominal from real return.
5. Distinguish simple from annualized return.
6. Separate investment return from currency return.
7. Use net property income rather than gross rent.
8. Record all cash-flow dates.
9. Test calculations independently.
10. Treat projections as assumptions, not facts.
