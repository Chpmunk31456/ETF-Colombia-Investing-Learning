# Repository Terminology and Editorial Style Guide

## Purpose

This guide establishes preferred terminology and presentation conventions for the educational repository.

## Primary Standards

- Define technical terms before relying on them.
- Explain acronyms at first use in each lesson.
- Use the preferred term from `GLOSSARY.csv`.
- Distinguish estimates from verified facts.
- Distinguish general education from jurisdiction-specific requirements.
- Use consistent formulas, currencies, dates, and percentage language.

## Preferred Repository Terms

Use:

- Emergency reserve
- Investable capital
- Liquid net worth
- Decision gate
- Stop condition
- Policy exception
- Publication candidate
- Reviewed draft
- Professional review
- Property equity
- Target allocation
- Allocation drift

## Terms Requiring Care

Do not use the following without explanation:

- Safe
- Guaranteed
- Risk free
- Best
- Always
- Never
- Profit
- Income
- Return
- Value
- Adviser
- Fiduciary
- Approved
- Published

## Currency

Use:

- COP 10 million
- USD 2,000
- EUR 500

State the base reporting currency in calculations.

## Percentages

Use:

- 5% for a percentage
- 5 percentage points for the difference between percentages
- 50 basis points for 0.50 percentage point

## Dates

Use ISO format where precision matters:

`YYYY-MM-DD`

Example:

`2026-08-01`

## Formulas

Present formulas in readable vertical form.

Example:

Net worth equals:

Total assets
minus total liabilities

State assumptions and units.

## Acronyms

At first use:

Exchange-traded fund (ETF)

Avoid creating an acronym that appears only once.

## Headings

Use one top-level heading per Markdown file.

Use headings in logical descending order.

## Lists

Use lists only when they improve scanning or sequence.

Avoid long lists without explanation.

## Tables

Every table should have:

- Clear headings
- consistent units
- defined terms
- sufficient surrounding explanation

## Disclaimers

Use disclaimers where content may be interpreted as:

- Personalized advice
- Current legal requirement
- Current tax rule
- Insurance interpretation
- Medical guidance
- Product recommendation
- Regulatory conclusion

## Jurisdiction

Label terms as:

- General
- Colombia
- United States
- Cross-border
- Contract-specific
- Institution-specific

## Estimates

Use wording such as:

- Estimated
- Assumed
- Illustrative
- Hypothetical
- Requires verification

Do not present assumptions as facts.

## Publication Status

Use only:

- Draft
- Reviewed Draft
- Publication Candidate
- Published
- Superseded
- Withdrawn

## Privacy

Do not place personal identifiers in:

- File names
- glossary examples
- templates
- screenshots
- repository paths
- issue descriptions

## Terminology Change

Before replacing a repository-wide term:

1. Open a terminology change record.
2. identify affected files.
3. confirm the preferred replacement.
4. review legal and tax implications.
5. update lessons and templates.
6. update glossary and acronym index.
7. run repository search.
8. perform QA review.
