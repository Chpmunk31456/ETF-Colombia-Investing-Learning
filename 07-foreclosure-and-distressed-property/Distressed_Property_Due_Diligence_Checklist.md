# Distressed Property Due-Diligence Checklist

## Official Process

- [ ] Auction authority verified
- [ ] Case number verified
- [ ] Official auction notice obtained
- [ ] Auction date and deadlines confirmed
- [ ] Deposit requirements confirmed
- [ ] Payment deadline confirmed
- [ ] Offer irrevocability understood

## Title

- [ ] Matrícula inmobiliaria confirmed
- [ ] Current Certificate of Tradition and Freedom obtained
- [ ] Registered owner verified
- [ ] Mortgages reviewed
- [ ] Embargoes reviewed
- [ ] Family-home restrictions reviewed
- [ ] Patrimonio de familia reviewed
- [ ] Usufruct rights reviewed
- [ ] Litigation reviewed
- [ ] Surviving obligations identified
- [ ] Registration path confirmed by attorney

## Possession

- [ ] Occupancy status confirmed
- [ ] Current occupants identified
- [ ] Lease status reviewed
- [ ] Delivery terms confirmed
- [ ] Possession procedure reviewed
- [ ] Estimated possession timeline documented
- [ ] Estimated legal cost documented

## Property Condition

- [ ] Exterior inspected
- [ ] Interior inspected where permitted
- [ ] Structural review completed
- [ ] Electrical review completed
- [ ] Plumbing review completed
- [ ] Roof reviewed
- [ ] Unauthorized construction reviewed
- [ ] Repair estimate obtained
- [ ] Contingency included

## Financial

- [ ] Independent market value estimated
- [ ] Comparable sales reviewed
- [ ] Rental comparables reviewed
- [ ] Property taxes confirmed
- [ ] Administration debt confirmed
- [ ] Utility debt confirmed
- [ ] Registration costs estimated
- [ ] Legal fees estimated
- [ ] Carrying costs estimated
- [ ] Financing confirmed
- [ ] Maximum bid approved
- [ ] Emergency reserve remains intact

## Exit

- [ ] Hold-and-rent scenario calculated
- [ ] Renovate-and-sell scenario calculated
- [ ] Personal-use scenario considered
- [ ] Worst-case scenario calculated
- [ ] Alternative exit identified

## Final Decision

- [ ] Attorney approval obtained
- [ ] Accountant or tax review completed
- [ ] Funding immediately available
- [ ] Risks understood
- [ ] Decision documented
