# Edición en español — ETF e inversión en Colombia

Esta carpeta contiene las traducciones al español de las lecciones del proyecto para facilitar su lectura y uso en familia.

## Cómo utilizar esta edición

1. Lea las lecciones en el orden indicado.
2. Converse en familia sobre las preguntas de reflexión.
3. No invierta dinero real únicamente con base en estas lecciones.
4. Verifique siempre la información vigente con fuentes oficiales.
5. Solicite asesoría profesional cuando existan implicaciones tributarias, legales, financieras o inmobiliarias.
