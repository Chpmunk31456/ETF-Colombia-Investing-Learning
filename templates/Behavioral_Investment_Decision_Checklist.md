## Objective

- [ ] Objective is written
- [ ] Time horizon is written
- [ ] Expected source of return is understood
- [ ] Alternatives were considered

## Evidence

- [ ] Primary evidence reviewed
- [ ] Contrary evidence reviewed
- [ ] Assumptions labeled
- [ ] Missing information identified
- [ ] Market value independently estimated
- [ ] Fees and taxes included
- [ ] Maximum plausible loss estimated

## Behavioral Risks

- [ ] No performance chasing
- [ ] No fear of missing out
- [ ] No attempt to recover a prior loss
- [ ] No excessive reliance on recent events
- [ ] No excessive reliance on one authority
- [ ] No social-pressure decision
- [ ] No sunk-cost justification
- [ ] No emotional auction escalation
- [ ] No automatic renewal without review
- [ ] No outcome-based reasoning

## Emotional State

Current state:

- [ ] Fatigued

- [ ] Emotional state permits careful judgment
- [ ] Decision should be delayed

## Limits

- [ ] Position limit respected
- [ ] Maximum property bid respected
- [ ] Emergency reserve protected
- [ ] Currency limit respected
- [ ] Institution limit respected
- [ ] Property-concentration limit respected
- [ ] Written investment policy respected

## Decision Controls

- [ ] Cooling-off period completed
- [ ] Pre-mortem completed
- [ ] Red-team review completed
- [ ] Trusted-person review completed
- [ ] Professional review completed where required
- [ ] Decision gate completed
- [ ] Exit conditions written
- [ ] Review date scheduled

## Automatic Stops

- [ ] No unexplained payment change
- [ ] No incomplete legal review
- [ ] No incomplete tax review
- [ ] No pressure to act immediately
- [ ] No guaranteed-return claim
- [ ] No use of required reserves
- [ ] Product can be explained clearly
- [ ] Worst-case outcome is affordable

## Final Decision

- [ ] Proceed
- [ ] Proceed with conditions
- [ ] Continue research
- [ ] Delay
- [ ] Reduce amount
- [ ] Obtain second opinion
- [ ] Reject
- [ ] Stop immediately
