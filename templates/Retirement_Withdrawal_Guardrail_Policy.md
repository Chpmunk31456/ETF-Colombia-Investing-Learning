## Yellow Status

Trigger examples:

- [ ] Portfolio decline exceeds threshold
- [ ] withdrawal rate rises above threshold
- [ ] reserve falls below target
- [ ] inflation exceeds assumption
- [ ] tax or currency cost rises materially
- [ ] income falls

Required actions:

- [ ] Freeze discretionary increase
- [ ] reduce discretionary spending
- [ ] use designated reserve
- [ ] review rebalancing
- [ ] postpone large purchase
- [ ] obtain professional review

## Red Status

Trigger examples:

- [ ] Essential spending threatened
- [ ] withdrawal rate exceeds hard limit
- [ ] reserve below minimum
- [ ] severe drawdown
- [ ] income interruption
- [ ] medical or household emergency
- [ ] currency-access failure

Required actions:

- [ ] Protect essential spending
- [ ] stop discretionary withdrawals
- [ ] activate continuity plan
- [ ] use approved emergency controls
- [ ] reassess portfolio allocation
- [ ] revise spending plan
- [ ] obtain urgent professional review
