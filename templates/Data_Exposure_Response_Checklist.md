# Data Exposure Response Checklist

## Immediate Actions

- [ ] Stop further sharing
- [ ] Remove public access
- [ ] Identify affected files
- [ ] Identify affected accounts
- [ ] Preserve evidence
- [ ] Record discovery time

## Credential Protection

- [ ] Password changed
- [ ] MFA reset
- [ ] Recovery codes replaced
- [ ] API keys revoked
- [ ] Private keys replaced
- [ ] Active sessions revoked
- [ ] Email account reviewed

## Financial Protection

- [ ] Bank contacted
- [ ] Broker contacted
- [ ] Credit-card issuer contacted
- [ ] Government portal reviewed
- [ ] Transactions reviewed
- [ ] Alerts enabled

## Repository Actions

- [ ] File removed from current branch
- [ ] Git history reviewed
- [ ] Other branches reviewed
- [ ] Tags reviewed
- [ ] Pull requests reviewed
- [ ] Fork exposure considered
- [ ] Credentials rotated regardless of deletion
- [ ] Secret scan rerun

## Recovery

- [ ] Trusted device confirmed
- [ ] Malware scan completed
- [ ] Backup verified
- [ ] Required files restored
- [ ] Sharing permissions corrected
- [ ] Incident register updated

## Professional and Legal Review

- [ ] Institution notification requirement reviewed
- [ ] Legal notification requirement reviewed
- [ ] Affected person notification reviewed
- [ ] Professional assistance obtained where required
