# Renovation Contractor Due-Diligence Checklist

## Contractor Identity

- [ ] Full legal name verified
- [ ] Identification verified
- [ ] Company registration verified
- [ ] Tax registration verified
- [ ] Address verified
- [ ] Telephone verified
- [ ] Email verified
- [ ] Receiving bank account verified

## Experience

- [ ] Similar projects reviewed
- [ ] Photographs reviewed
- [ ] Three references requested
- [ ] References contacted
- [ ] Current project visited where possible
- [ ] Completion history reviewed
- [ ] Warranty history reviewed
- [ ] Dispute history reviewed where available

## Legal and Insurance

- [ ] Professional license reviewed where applicable
- [ ] Insurance reviewed
- [ ] Worker coverage reviewed
- [ ] Subcontractor responsibility reviewed
- [ ] Building requirements reviewed
- [ ] Permit responsibility documented
- [ ] Attorney review completed where appropriate

## Proposal

- [ ] Written scope included
- [ ] Labor included
- [ ] Materials included
- [ ] Quantities included
- [ ] Brand and quality specified
- [ ] Exclusions listed
- [ ] Schedule included
- [ ] Payment milestones included
- [ ] Warranty included
- [ ] Cleanup included
- [ ] Taxes included or identified
- [ ] Proposal validity stated

## Contract

- [ ] Parties correct
- [ ] Property correct
- [ ] Scope attached
- [ ] Plans attached
- [ ] Price confirmed
- [ ] Payment schedule confirmed
- [ ] Start date confirmed
- [ ] Completion date confirmed
- [ ] Change-order process included
- [ ] Inspection rights included
- [ ] Defect correction included
- [ ] Retention included
- [ ] Warranty included
- [ ] Delay terms included
- [ ] Termination rights included
- [ ] Dispute process included
- [ ] Final document delivery included

## Risk Assessment

- [ ] No full advance payment required
- [ ] Bank account matches legal party
- [ ] Contractor accepts inspections
- [ ] Contractor accepts photographic documentation
- [ ] Contractor accepts written changes only
- [ ] Contractor accepts milestone payments
- [ ] Contractor accepts retention
- [ ] Contractor can explain exclusions
- [ ] Contractor can provide required documents

## Final Status

- [ ] Continue verification
- [ ] Request revised proposal
- [ ] Obtain legal review
- [ ] Reject contractor
- [ ] Approve for contract
