# Portfolio Performance Reconciliation Checklist

## Scope

- [ ] Reporting scope defined
- [ ] Start date confirmed
- [ ] End date confirmed
- [ ] Base currency confirmed
- [ ] All relevant accounts included
- [ ] Restricted assets identified
- [ ] Property treatment documented

## Beginning and Ending Values

- [ ] Beginning statements obtained
- [ ] Ending statements obtained
- [ ] Market values verified
- [ ] Cash balances verified
- [ ] Loan balances verified
- [ ] Property valuations supported

## Cash Flows

- [ ] Contributions recorded
- [ ] Withdrawals recorded
- [ ] Internal transfers identified
- [ ] Internal transfers eliminated
- [ ] Dividends recorded
- [ ] Interest recorded
- [ ] Rental cash flow recorded
- [ ] Fees recorded
- [ ] Taxes and withholding recorded

## Reconciliation

- [ ] Beginning value entered
- [ ] Net cash flows entered
- [ ] Investment result calculated
- [ ] Ending value matched
- [ ] Reconciliation difference is zero or explained
- [ ] Exceptions logged
- [ ] Material differences resolved

## Return Calculations

- [ ] Time-weighted return calculated
- [ ] Money-weighted return calculated
- [ ] Nominal return calculated
- [ ] Real return calculated
- [ ] Currency effect calculated
- [ ] Maximum drawdown calculated
- [ ] Recovery period reviewed

## Benchmark

- [ ] Benchmark relevant
- [ ] Benchmark period matches
- [ ] Benchmark currency matches
- [ ] Income treatment matches
- [ ] Blended weights documented
- [ ] Benchmark source retained
- [ ] Relative return calculated

## Attribution

- [ ] Asset-allocation effect reviewed
- [ ] Security-selection effect reviewed
- [ ] Currency contribution reviewed
- [ ] Income contribution reviewed
- [ ] Fee drag reviewed
- [ ] Tax drag reviewed
- [ ] Property contribution reviewed
- [ ] Leverage effect reviewed

## Final Review

- [ ] Objective evaluated
- [ ] Risk evaluated
- [ ] Process quality evaluated
- [ ] Results not presented as guaranteed
- [ ] Estimates clearly labeled
- [ ] Professional review obtained where required
- [ ] Completed report stored securely outside Git
