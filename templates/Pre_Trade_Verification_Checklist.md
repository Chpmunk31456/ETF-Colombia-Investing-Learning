# Pre-Trade Verification Checklist

## Financial Readiness

- [ ] Emergency reserve remains intact
- [ ] Essential expenses are funded
- [ ] Pilot loss would not affect household finances
- [ ] Investment Policy Statement permits the product
- [ ] Portfolio allocation remains within limits

## Product

- [ ] Legal product name verified
- [ ] Ticker or identifier verified
- [ ] Exchange verified
- [ ] Fund domicile verified
- [ ] Issuer verified
- [ ] Official prospectus reviewed
- [ ] Product purpose documented
- [ ] Main risks documented
- [ ] Tax questions documented
- [ ] Exit conditions documented

## Institution

- [ ] Legal entity verified
- [ ] Regulator verified
- [ ] Custodian identified
- [ ] Receiving account verified
- [ ] Fee schedule reviewed
- [ ] Withdrawal procedure reviewed
- [ ] Official support contact retained

## Security

- [ ] Unique password used
- [ ] MFA enabled
- [ ] Recovery codes stored
- [ ] Authorized devices reviewed
- [ ] Login alerts enabled
- [ ] Trade alerts enabled
- [ ] Withdrawal alerts enabled
- [ ] API withdrawal permission disabled

## Order

- [ ] Correct account selected
- [ ] Buy or sell direction verified
- [ ] Correct ticker selected
- [ ] Correct quantity entered
- [ ] Order type selected
- [ ] Limit price reviewed where applicable
- [ ] Bid-ask spread reviewed
- [ ] Estimated commission reviewed
- [ ] Estimated currency cost reviewed
- [ ] Total order value reviewed

## Post-Trade

- [ ] Trade confirmation saved
- [ ] Settlement date recorded
- [ ] Cost basis recorded
- [ ] Holdings reconciled
- [ ] Cash balance reconciled
- [ ] Decision log updated
- [ ] Withdrawal test scheduled
