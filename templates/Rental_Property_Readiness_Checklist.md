# Rental Property Readiness Checklist

## Legal and Building

- [ ] Registered ownership confirmed
- [ ] Legal possession confirmed
- [ ] Building rental rules reviewed
- [ ] Intended rental model permitted
- [ ] Insurance requirements reviewed
- [ ] Tax review completed
- [ ] Lease reviewed by qualified counsel

## Property Condition

- [ ] Safety inspection completed
- [ ] Required repairs completed
- [ ] Locks changed
- [ ] Utilities active
- [ ] Appliances tested
- [ ] Cleaning completed
- [ ] Inventory completed
- [ ] Photographs retained
- [ ] Emergency contacts posted where appropriate

## Market Analysis

- [ ] Comparable rents reviewed
- [ ] Same-building rents reviewed
- [ ] Vacancy assumptions documented
- [ ] Conservative rent established
- [ ] Administration treatment confirmed
- [ ] Expected leasing period estimated

## Financial

- [ ] Gross rent calculated
- [ ] Effective gross income calculated
- [ ] Operating expenses calculated
- [ ] Net operating income calculated
- [ ] Debt service included
- [ ] Vacancy reserve funded
- [ ] Repair reserve funded
- [ ] Capital reserve funded
- [ ] Legal reserve funded
- [ ] Worst-case cash flow tested

## Tenant Process

- [ ] Written screening criteria established
- [ ] Identity-verification process established
- [ ] Income-verification process established
- [ ] Rental-history process established
- [ ] Reference-check process established
- [ ] Guarantor or guarantee process established
- [ ] Personal-data safeguards established

## Lease and Move-In

- [ ] Lease approved
- [ ] Payment method documented
- [ ] Late-payment process documented
- [ ] Maintenance responsibilities documented
- [ ] Inspection rights documented
- [ ] Move-in inventory prepared
- [ ] Key and access register prepared
- [ ] Utility readings prepared
- [ ] Tenant acknowledgment prepared

## Operations

- [ ] Rent ledger created
- [ ] Maintenance request channel created
- [ ] Emergency process created
- [ ] Inspection schedule created
- [ ] Renewal process created
- [ ] Arrears process created
- [ ] Property manager verified where applicable
- [ ] Monthly reconciliation process created

## Final Status

- [ ] Continue preparation
- [ ] Resolve legal issue
- [ ] Complete repairs
- [ ] Increase reserves
- [ ] Obtain professional review
- [ ] Ready to market
- [ ] Reject rental strategy
