## Approval

- [ ] Investment thesis current
- [ ] Investment Policy Statement permits transaction

- [ ] Liquidity gate green
- [ ] Emergency reserves protected
- [ ] Tax review complete
- [ ] Cooling-off period complete

## Account

- [ ] Broker legal entity verified
- [ ] Correct account selected
- [ ] Account registration correct
- [ ] Base currency confirmed
- [ ] Available settled cash confirmed
- [ ] Margin not used unintentionally
- [ ] MFA enabled
- [ ] No security alerts present

## Security

- [ ] Full legal name verified
- [ ] Ticker verified
- [ ] Identifier verified
- [ ] Exchange verified
- [ ] Currency verified
- [ ] Share class verified
- [ ] Domicile verified
- [ ] Distribution policy verified
- [ ] Not leveraged or inverse unless explicitly approved
- [ ] Prospectus and factsheet reviewed

## Order

- [ ] Buy or sell instruction correct
- [ ] Quantity correct
- [ ] Decimal placement correct
- [ ] Order type correct
- [ ] Limit or stop correct
- [ ] Time-in-force correct
- [ ] Estimated gross value reviewed
- [ ] Estimated commission reviewed
- [ ] Bid-ask spread reviewed
- [ ] Trading-hours status reviewed

## Risk

- [ ] Maximum loss understood
- [ ] Allocation after trade calculated
- [ ] Currency exposure calculated
- [ ] No urgent pressure
- [ ] No duplicate order
- [ ] No conflicting recurring instruction
- [ ] Exit rule documented
